# Cache

### Goals
- The trainee will understand the basic concepts of caching
- The trainee will learn about different caching strategies

### Tasks
- What is caching and why is it useful in web applications?
- What are the main types of caching (e.g. in-memory, distributed)?
- What is the difference between a cache and a database?
- What is cache hit and cache miss?
- What is a cache eviction policy?
- What are common cache eviction policies? (e.g., LRU, LFU, FIFO)
- What is the difference between write-through and write-back(Write-Behind) caching?
- What is the difference between Cache-aside and read-through caching?
- What is cache invalidation, and why is it considered hard?
- How does Redis store data in memory?
- How do you set expiration (TTL) for a key in Redis?
