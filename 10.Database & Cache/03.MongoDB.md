### Goals
- The trainee will understand the basic concepts of MongoDB
- The trainee will know how to design schemas and work with collections
- The trainee will know how to query and aggregate data efficiently

### Tasks
- What is a document, collection, and database in MongoDB?
- What is BSON and how is it different from JSON?
- How do you insert a document into a collection?
- How do you query documents using find()?
- What is the difference between updateOne, updateMany, and replaceOne?
- How do you delete documents?
- How do you filter documents using operators (e.g., $eq, $gt, $in)?
- What is an index and why is it important?
- How do you create an index?
- What are the trade-offs of indexing?
- What is the aggregation pipeline?
- How do you use stages like $match, $group, $project, $sort?
- When would you use aggregation instead of simple queries?
- What is the difference between embedded documents and referencing?
- When would you denormalize your data?
- What are the advantages and disadvantages of schema-less design?
- What are transactions in MongoDB and when would you use them?
- What is replication and how does a replica set work?
- What is sharding and when is it needed?
- What is the role of the _id field?
- Why is it a bad idea to store sensitive data without encryption?
- What are ways to secure MongoDB (authentication, roles, TLS)?
- How do you manage secrets (e.g., connection strings)?
- What is mongosh? What is mongoDB Compass?
- Download [MongoDB-Community Edition](https://www.mongodb.com/docs/manual/administration/install-community/#std-label-install-mdb-community-edition)
Or the official MongoDB Docker image. Download [MongoDB Compass](https://www.mongodb.com/try/download/compass). Start a MongoDB instance and connect to it via mongosh, and MongoDB Compass.
- Using mongosh, create a DB called bikini_bottom, and add a document for spongebob in 'characters' collection. Give him the fields name, job, hobbies, and lives_in.
- Add patrick to the collection. Give him the fields name, current_activity, is_hungry.
- Run db.characters.find().pretty() Notice how the data is schema-less.
- Update spongebob to have another field. Be creative.
- Using MongoDB compass, connect to your DB, and look at the documents using the UI. Go ahead and practice adding more documents (squidwards, for example) and editing them using the GUI.
