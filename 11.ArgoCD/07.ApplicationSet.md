### Goals
- The trainee will understand what an ApplicationSet is and which problems it solves
- The trainee will know the different generator types and when to use each one
- The trainee will understand the difference between ApplicationSet and App of Apps

### Tasks
- Read about ApplicationSets
- Which component turns an ApplicationSet into Applications?
- What is a **generator**? What is a **template**? How do they work together?
- Explain each generator and give a use case for it:
  - List
  - Cluster
  - Git - directory generator
  - Git - file generator
  - Matrix
  - Merge
  - SCM Provider
  - Pull Request
- What is `goTemplate: true`? Why is it recommended? How do you write a parameter with it?
- With a Git directory generator on `apps/*`, what happens when you add a new folder? And when you delete one?
- What do `syncPolicy.preserveResourcesOnDeletion` and `applicationsSync` (e.g. `create-only`, `create-update`) control? Why are they important for safety?
- What is **Progressive Sync** (`RollingSync` strategy)?
- Compare ApplicationSet with App of Apps. When would you use each one? Can you use both together?
- Security: why can't you let any team create ApplicationSets in the `argocd` namespace? (hint: the `project` field in the template)
