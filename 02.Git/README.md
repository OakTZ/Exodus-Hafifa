
### Goals
- The trainee will understand the basics of working with Git

### 🛠️ Tasks

1. **Tutorial**
   - Complete the [Git Immersion Tutorial](https://gitimmersion.com/index.html).
   - While going through the tutorial, answer the following questions:

2. **Git Concepts**
   - What is a **Commit**?
   - What is a **Branch**?
   - What is the **HEAD**?
   - What is the difference between **remote** and **local** in Git?

3. **Branching in Git**
   - How do you create a new branch?
   - How can you switch between branches?
   - What happens to edited files when switching between branches?

4. **Advanced Git Commands**
   - How does `git stash` work?
   - How does `git reset` work?

5. **Conflict Resolution**
   - In your own repository:
     - Create a conflict between two branches.
     - Resolve the conflict.
     - Merge the branches.

6. **Rebase**
   - What is `git rebase`?
   - When is it useful?

7. **GitLab Setup**
   - Create a [GitLab](https://gitlab.com/) account if you don’t have one.
   - Create a repository.
   - Use this repository to store all your **Ansible** scripts going forward.
