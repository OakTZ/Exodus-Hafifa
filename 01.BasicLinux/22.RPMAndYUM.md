
> **Optional:** GKE nodes run Container-Optimized OS, so you won't use these much day to day, but they come up on VMs and in container base images.

### Goals
- The trainee will understand what package managers are and how RPM, YUM, DNF and APT relate
- The trainee will know the basic package management commands

### Tasks
- List the differences between `rpm`, `yum`, `dnf`, `dpkg` and `apt`
- List the installed packages, then install and remove a package using a low-level and a high-level tool
- List the configured repositories
- Find which package owns a specific file

### Questions
- Why use `yum`/`dnf` instead of `rpm`?
- What is the relationship between `yum` and `dnf`?
- When would you use `yum`, `dnf`, `apt` or `apk`?
- How can you see the dependencies of a package?
- Why should you avoid installing packages manually on nodes managed by Kubernetes?
