## 🚀🐘 PostgreSQL on Kubernetes Project (with Redis Cache)

Before starting, you will use **FastAPI** – a modern, high-performance web framework for building APIs with Python 3.7+.

Get familiar with FastAPI by completing the **"First Steps"** tutorial:  
👉 [https://fastapi.tiangolo.com/tutorial/](https://fastapi.tiangolo.com/tutorial/)

This project demonstrates how to deploy a **PostgreSQL database** on Kubernetes with:

- A **FastAPI application** that connects to PostgreSQL
- A **Kubernetes CronJob** that backs up the database daily
- **Redis** as a caching layer to optimize database reads
- All components are defined using Kubernetes manifests

---

## 🎯 Goals

- Deploy a persistent PostgreSQL instance using a CloudNativePG operator
- Create a FastAPI microservice that interacts with PostgreSQL and Redis
- Backup the PostgreSQL database using a Kubernetes CronJob
- Expose the FastAPI app via Kubernetes Service

---

## 📦 Components

### 1. PostgreSQL on Kubernetes
- Deploy PostgreSQL via **CloudNativePG operator**
- Use **Secret** for user credentials

### 2. FastAPI Application
- Python FastAPI app with:
  - `POST /newUsers/` – insert user
  - `GET /getAllUsers/` – list users with Redis caching
- Deployed via Kubernetes **Deployment**
- Connects to PostgreSQL and Redis via environment variables (os module in python)
- Exposed via a **ClusterIP Service**

### 3. Redis Cache
- Redis deployed as a single **Deployment**
- Used to cache the `/getAllUsers/` response
- Invalidation handled on new user creation
- Exposed via a **Service**

### 4. Backup CronJob
- Runs daily at 02:00 AM
- Dumps PostgreSQL database using `pg_dump`
- Connection to the DB is done with mounted secret as credentials
- Stores backups in a PVC
- Scheduled via **Kubernetes CronJob**
