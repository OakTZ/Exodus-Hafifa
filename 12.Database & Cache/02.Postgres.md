### Goals
- The trainee will understand the basic concepts of Postgres

### Tasks
- What is postgreSQL? Why is it so popular?
- What is pgAdmin? Do we have to use it?
- What are primary keys and foreign keys? Why do we use them?
- What are CRUD operations?
- What are the system catalogs? When and why would you use them?
- What are Data Types?

- Learn SQL basics with [SQLBolt SQL Tutorial](https://sqlbolt.com/)
- Download [PostgreSQL](https://www.postgresql.org/download/windows/)
and [pgAdmin](https://www.pgadmin.org/download/pgadmin-4-windows/)
- Launch a PosgreSQL DB instance and log into it using pgAdmin. You are probably surprised with the amount of tabs on pgAdmin. Go ahead, explain them (No need to go into too much detail, explain each tab shortly and find where you can see the DB tables) Once you did, practice creating a few tables with the UI and with the SQL tool.
